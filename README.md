# AI Resume Analyzer

## Project Overview

AI Resume Analyzer is a Python-based web application developed using Streamlit to help job seekers analyze their resumes and identify areas for improvement based on their selected job roles. It provides useful insights into resume content and helps candidates understand how well their skills match job requirements.

## Key Features

- **Resume Upload:** Allows users to upload resumes in PDF format.
- **Job Role Selection:** Enables users to select their preferred job role for personalized analysis.
- **Resume Content Analysis:** Extracts and analyzes text from uploaded resumes.
- **Skills Matching:** Compares the skills available in the resume with the required skills for the selected job role.
- **Missing Skills Detection:** Identifies important skills that are missing from the resume.
- **ATS-Style Scoring:** Provides a score based on resume analysis and skill matching.
- **Improvement Suggestions:** Offers recommendations to improve resume content and presentation.
- **Data Visualization:** Displays analysis results through graphical representations using Plotly.
- **PDF Report Generation:** Generates downloadable PDF reports containing resume analysis results.

## Technologies Used

- **Python:** Core programming language used for application development.
- **Streamlit:** Used to create an interactive web application.
- **Plotly:** Used for visualizing resume analysis results.
- **ReportLab:** Used to generate downloadable PDF reports.

## Project Objective

The main objective of this project is to develop a simple and user-friendly resume analysis platform that helps students, fresh graduates, and job seekers understand their resume strengths and weaknesses. It helps users identify missing skills, evaluate their job-role compatibility, and discover opportunities to improve their resumes.

## Conclusion

AI Resume Analyzer demonstrates the practical implementation of Python programming, web application development, data visualization, and PDF generation to solve a real-world career-related problem. It aims to support candidates in preparing better resumes and improving their placement opportunities.
